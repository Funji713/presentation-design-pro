# Evidence-Led Visual Style

Use for new decks and substantive redesigns. For academic work, apply [personal preferences](personal-academic-preferences.md). Visual explanation includes scientific figures, tables, exact diagrams, and annotations; it does not require generated illustrations.

## Visual system

For PPTX, first use an accessible template already supplied, explicitly selected, or explicitly configured locally by the current user; no default template is bundled. Use its aspect ratio, masters, typography, palette, and chrome. Adapt geometry to evidence, replace demo text and irrelevant photos, and keep the source template unchanged. A supplied current reference may guide composition/density when authorized.

Use the chosen template's semantic colors to group stages and highlight the current operation, condition, comparison, or readout. The SuperAnimal example uses a 16:9 light canvas, Livvic/Lato typography, lavender/cyan/yellow accents, and selective red emphasis; these describe that example rather than a reusable default. Maintain contrast and non-color cues. Do not copy incidental font reductions as a global rule.

If a template or visual system is missing, continue evidence and narrative planning, then request the user's template selection only if no accessible supplied, selected, or explicitly configured local template exists before template-specific production. Do not silently fall back to the example palette or a blank design.

## Choose visuals by teaching job

| Job | Suitable composition |
| --- | --- |
| Workflow | Precise flow with input, transformation, output and attached conditions |
| Why a component exists | Concrete before/after or mapping example and causal sentence |
| Architecture | Original or faithful explanatory diagram with readable entities/pathways |
| Reported result | Enlarged source panel with axes/legend and selected annotation |
| Quantitative comparison | Editable table/chart with metric, baseline, conditions and differences |
| Continuing worked case | One plot beside selected values, data budgets and interpretation |
| Chapter introduction | Clean chapter name; image optional |
| Abstract spatial idea | Source-grounded illustration only when it adds understanding |

Give evidence enough area to read at delivery scale. Preserve aspect ratio, axes, legends, uncertainty, and necessary context. Crop a relevant panel rather than shrinking a multi-panel paper figure. Place explanations beside what they explain. Reuse relevant cases or figures when continuity helps.

Boxes/arrows suit real modules, boundaries, mappings, and direction. Avoid decorative card grids without replacing accurate flows with artwork. Repeated visual grammar helps comparison. Change composition when the job changes, not to meet a variety quota.

## Images and editable elements

Use original imagery for actual study examples/results. Keep titles, values, labels, citations, newly created tables/charts, and emphasis editable according to the production workflow. Do not rasterize whole slides to match the reference. Follow production rules for technical diagrams and other assets.

Generate conceptual imagery only when it clarifies a concept better than available figures or exact diagrams. Use image generation for an asset, not an entire slide, with the needed crop and space for native labels. Avoid embedded text/numbers, generic science decoration, fabricated data/screenshots/logos. Distinguish illustrations from evidence.

Covers, contents, dividers and closing pages need no main visual. A typographic title or plain chapter reset is valid. Do not add decoration merely to fill whitespace.

## Rendered review

Inspect contact sheets for sequence and full-size method/result pages for precision. Fix small evidence despite available space, lost legends/conditions in crops, detached annotations, competing highlights, overflow, distorted images, unreadable sources, ornamental distractions, or missing baselines/units/conditions.

Use the stored calibration pairs when needed. Preserve their useful evidence scale and reading order while correcting incidental defects.
